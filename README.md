## ⚙️ How Shared Defaults Work

GitHub supports default community-health files in a public repository named `.github`.

Eligible repositories owned by the same account can use these defaults when they do not provide their own corresponding files.

Keep in mind:

- Repository-specific community files take precedence over shared defaults.
- Issue templates are used as defaults only when the target repository's configuration allows it.
- Each project must provide its own applicable license.
- This repository's CODEOWNERS rules do not automatically assign code ownership in other repositories.
- GitHub Actions workflows here are not automatically executed in every other project.
- Custom labels are not automatically synchronized across repositories.

Individual projects may define additional requirements depending on their language, platform, and intended audience.
