# 🆘 Support & Help

Need help with an Iconical project? You've come to the right place! ❤️

Whether you're experiencing a bug, having trouble installing software, or have a general question, this guide will help you find the right support channel.

## 📚 Start With the Documentation

Before opening a support request, we recommend checking:

- The project's README.
- Installation and configuration instructions.
- Existing GitHub issues.
- Available GitHub Discussions.
- Release notes or troubleshooting guides.

Many common questions may already have an answer.

If you cannot find what you need, you're welcome to reach out!

## 🐛 Report a Bug

Found an unexpected error or behavior?

Please open an issue in the **affected project's repository**, using the Bug Report template where available.

Try to include:

- A clear description of the problem.
- The affected version.
- Steps to reproduce the issue.
- Relevant environment information.
- Sanitized logs or screenshots, where helpful.

Do not include passwords, access tokens, or private user information.

For security vulnerabilities, use the private reporting instructions below.

## 💡 Suggest a Feature

Have an idea that could improve one of our projects?

Use the project's Feature Request or Improvement Suggestion template, where available.

Explain what you would like to change, why it would help, and any relevant examples.

Feature suggestions are appreciated, although not every request can be implemented.

## 🔒 Security Vulnerabilities

**Do not report exploitable security vulnerabilities through public GitHub issues.**

For confidential security reporting:

- **Email:** [security@iconical.dev](mailto:security@iconical.dev)
- **GitHub:** Private vulnerability reporting, where enabled.
- **Instructions:** [Security Policy](https://iconical.dev/policies/security)

Please include enough information to understand and reproduce the vulnerability without unnecessarily exposing users or sensitive data.

## 💬 Community Support

Want to ask a question or talk with other developers?

You can use:

- [Iconical Discord Community](https://iconical.dev/discord)
- GitHub Discussions in the relevant repository, where enabled.

Community support is voluntary and may depend on contributor availability.

Please follow our [Code of Conduct](https://github.com/imthatdev/.github/blob/master/CODE_OF_CONDUCT.md) when participating.

## 🧩 Product and Marketplace Support

Some Iconical products are distributed through third-party marketplaces or platforms.

When seeking support, include:

- The product name.
- The affected version.
- The marketplace or download source, where relevant.
- Your operating system or development environment.
- A description of the problem.

Purchases, refunds, licensing, and platform account issues may need to be handled through the applicable marketplace or payment provider.

Where specific support commitments exist, the applicable purchase terms or product documentation govern them.

## ⏳ Response Times

Iconical is an independent development brand, so response times may vary depending on availability, issue complexity, and project maintenance status.

We aim to review legitimate inquiries within a reasonable timeframe, but cannot guarantee immediate responses or individual support for every request.

For project-specific support availability, review the relevant documentation.
